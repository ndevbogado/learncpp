TEMPLATES

Un TEMPLATE es un modelo de funciones o clases que creamos una vez, con parametros genericos. Estos
parametros recien son definidos cuando se utiliza el TEMPLATE. Esto permite una mayor flexibilidad a
la hora de trabajar con secciones de codigo que conservan una estructura muy similar (como lo es el
OVERLOADING de funciones).

Hay tres tipos de TEMPLATES:

    1-	Type template parameters (donde los parametros del template representan un type)
    2-	Non type template parameters (donde los parametros del template representan un constexpr
    value)
    3-	Template template parameters (donde los parametros del template representan un template -
    usados con menos frecuencia)

Estructutra para definir un TEMPLATE:

    template <typename T>
    T foo(T var){...}

Estructura para llamar a un TEMPLATE:
    
    foo<TYPE>(TYPE var)

[1] www.learncpp.com	https://www.learncpp.com/cpp-tutorial/function-templates/

TEMPLATES para varios template type parameters:

    template<T var1, U var2>
    auto foo (T var1, U var 2)

# nota: es recomendable utilizar una llamada comun de funciones cuando tenemos un template con return type AUTO
